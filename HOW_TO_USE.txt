HOW TO USE: dataset-builder
====================================

PURPOSE
  Turns any target folder of raw documents (PDFs, Markdown, TXT, manuals,
  or research) into a production-grade, dual-access dataset. The resulting
  dataset is optimized for both Producer Pal the APP (Live Actions Helper /
  Genius) and AI Skills (producer-pal-genius, ai-database-browser, Claude,
  Grok, Antigravity). Destination MUST be specified first before building.

CAPABILITIES
  - Enforce destination specification before building to protect file organization
  - Extract text cleanly from PDFs (PyPDF / PyMuPDF), Markdown, TXT, JSON, and HTML
  - Generate modular, categorized Markdown chapters under token limits (<15,000 chars)
  - Create semantic ~500-word chunks with section anchors and keyword tags
  - Build SQLite FTS5 database with Porter stemming and BM25 relevance ranking
  - Export Apache Parquet (.parquet) and JSON Lines (_chunks.jsonl, _docs.jsonl)
  - Generate a standalone executable search tool (search.py)
  - Generate high-density Producer Pal App router table (INDEX.md) with:
    * Decide First quick routing table
    * Live Actions / Producer Pal capability matrix (Native vs Handoff)
    * Real runnable Live Actions device and MIDI action blueprints
    * Full categorized document catalog
  - Generate schema documentation (SCHEMA.md) and overview guide (README.md)
  - Automatically register new databases in ai-database-browser and master INDEX.md

USE CASES
  - "Turn this folder of plugin manuals into a dataset in B:\DATABASES"
  - "Convert these sound design notes into an indexed database Producer Pal can read"
  - "Take this music theory folder and build a dataset with SQLite FTS5 and INDEX.md"
  - "Create a structured dataset from B:\Documents\TRAINING DOCS\NewFolder"
  - "Add this new manual or research folder into an existing dataset without overwriting it"

IDEAS
  - Keep raw PDFs alongside the dataset so human and AI readers both have access
  - Use --domain music for Ableton-specific action blueprints, or --domain general
  - Pair with ai-database-browser to immediately search across all studio datasets
  - Open the generated INDEX.md in Live Actions Helper to verify token navigation
  - Use incremental addition (--add) whenever adding individual manuals or new release notes
